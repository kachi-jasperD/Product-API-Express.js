# Project Setup Guide

## Getting Started

Follow the steps below to set up and run the project locally.

### 1. Clone the Repository
```bash
git clone <repository-url>
cd <repository-name>
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```

---

## API Testing with Postman

To test the APIs using Postman, follow the steps below.

1. Open the Postman documentation:
   https://documenter.getpostman.com/view/2449601/2sBXVZnZaq

2. Click the **"Run in Postman"** button located at the top-right corner of the page.

3. A dialog window will appear prompting you to choose one of the following:
   - **Postman for Web**
   - **Postman for Mac**

4. Select your preferred option, continue with the import process, and run the collection.

---

## Notes
- Ensure Node.js and npm are installed on your machine before starting.
- Postman must be installed or accessible via the web to run the API collection.
